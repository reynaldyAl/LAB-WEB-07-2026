# Pustaka Senja

Aplikasi multi-halaman Ruang Baca Pustaka Senja (Tugas Praktikum 8 — Next.js Intro).
Dibangun dengan Next.js (App Router), JavaScript, dan Tailwind CSS.

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Halaman

- `/` — Beranda (Hero + statistik koleksi)
- `/katalog` — Katalog buku (filter kategori, tombol favorit)
- `/katalog/[id]` — Detail buku (dynamic route)
- `/usulan` — Form usulan buku
